# RPE 缓动表

缓动函数 f(t)，t ∈ [0,1]，f(0)=0，f(1)=1。事件在 [t0,t1] 内从 start 变到 end 时，
`value(t) = start + (end-start) * f((t-t0)/(t1-t0))`。

## 序号表

| 类型 | In | Out | InOut |
| --- | --- | --- | --- |
| fixed（恒 0） | 0 | 0 | 0 |
| linear | 1 | 1 | 1 |
| sine | 3: `1-cos(πt/2)` | 2: `sin(πt/2)` | 6: 两半拼接 |
| quad | 5: `t²` | 4: `1-(t-1)²` | 7: 两半拼接 |
| cubic | 9: `t³` | 8: `1+(t-1)³` | 12: 两半拼接 |
| quart | 11: `t⁴` | 10: `1-(t-1)⁴` | 13: 两半拼接 |
| quint | 15: `t⁵` | 14: `1+(t-1)⁵` | 无 |
| expo | 17: `2^(10t-10)` | 16: `1-2^(-10t)` | 无 |
| circ | 18: `1-√(1-t²)` | 19: `√(1-(t-1)²)` | 22: 两半拼接 |
| back | 21: `(2.70158t-1.70158)t²` | 20: `(2.70158t-1)(t-1)²+1` | 23: 两半拼接 |
| elastic | 25 | 24 | 29 |
| bounce | 27 | 26 | 28 |

- elastic Out（24）：`2^(-10t)·sin[(10t-0.75)·2π/3]+1`；In（25）与之中心对称。
- bounce Out（26）：标准弹跳分段（7.5625t² 系列）；In（27）中心对称。
- "两半拼接"（IO 型）：前半 `In(2t)/2`，后半 `Out(2t-1)/2 + 0.5`。

## 选型建议

- **1（linear）**：匀速移动、速度事件、机械感。
- **2（outSine）/ 6（IOsine）**：默认首选，自然顺滑；移动/旋转演出最常用。
- **4/5（quad）、8/9（cubic）**：比 sine 更"弹"一点的加减速。
- **16/17（expo）**：瞬间加速/减速，适合 build-up 冲刺、急停。
- **18/19（circ）**：强度介于 cubic 与 expo 之间，摄像机式移动常用。
- **20/21（back）**：回弹过冲，适合小幅度强调。
- **24/25（elastic）**：抖动收敛，慎用，易廉价。
- **26/27（bounce）**：落地弹跳，节奏点的下落强调。
- **0（fixed）**：事件值恒为 start？注意：0 号在 RPE 中表示整段值恒为 0（相对量），仅用于 incline 等占位，**不要**用它表达"保持某值"——"保持"应当用首尾相同值的 1 号线性事件。

## 截取（easingLeft / easingRight）

设原缓动 f，截取区间 [l, r]（0 ≤ l < r ≤ 1），新缓动为
`g(t) = [f(r)-f(l)] · f((t-l)/(r-l)) + f(l)`。
用途：只取曲线的一段（如只要 outCubic 的尾段做柔性刹车）。1 号 linear 截取无效果。

## 贝塞尔缓动

`bezier: 1`，`bezierPoints: [c1x, c1y, c2x, c2y]`，三次贝塞尔（起点 (0,0)，终点 (1,1)）：

```
x(t) = 3c1x(1-t)²t + 3c2x(1-t)t² + t³
y(t) = 3c1y(1-t)²t + 3c2y(1-t)t² + t³
```

约束 c1x、c2x ∈ [0,1]。近似 CSS 缓动：`ease = [0.25,0.1,0.25,1.0]`，`ease-in-out = [0.42,0,0.58,1]`。
设置 bezier 后忽略 easingType。
