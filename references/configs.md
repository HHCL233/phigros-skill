# 配置库与表演手法库

排键与演出的**推荐素材库**（优先从库内选取，也可按实际情况调整或新增）。写谱排键时读本文；采音、难度标尺、密度、手感红线见 [charting.md](charting.md)。

## 配置库（AI 排键的推荐配置库）

> **AI 排键推荐优先从本库选取配置**，可自由选择配置、替换拍位/x/方向/镜像复用；
> **也可按实际情况调整参数或新增配置**（编号顺延）。
> **同一配置尽量不重复**：同一手法反复出现时换 x、镜像、换拍位或穿插其它配置保持变化。
> **识别口径：必须把所有判定线的音符按时间合并成一条时间轴（游玩视角）再识别配置**——
> 拆线手法会把同一配置的音符拆到多条线上，单线视角看到的是残缺片段。
> **生成骨架**：`scripts/gen_config.py` 按「配置编号 + 区间 + 首音 x + 几分」输出对应的 notes JSON
> （只输出 JSON，由 AI 决定写进哪条判定线）；生成结果只是骨架，**必须按采音逐音微调后再用**（见 SKILL.md 工作流第 3 步）。

**H. 结构手法**（组织方式，与键型叠加使用）

- **音符与表演分离**：主线承载可判音符，演出全放表演线；`scaffold.py --lines 6` 起步。
- **孪生副线**：2~8 条线放完全相同的音符（同刻同型同 x）做多份下落画面，主线照常流动。
- **拆线分段**：音符按段落分到多条线（6~23 条音符线），各线 speedEvents 只覆盖自己的段落。
- **拆线瀑布**：连续 1/16~1/4 拍的音符按时间轮流分配到多条专用线，各线用独立速度事件做不同下落轨迹。
  两种形态：**Drag 瀑布**（8~17 连纯 Drag 轮流换线，或 8 Drag+1 Tap/Hold 收尾；合并视角是连续 Drag 流）
  与 **Tap-Drag 交替瀑布**（25 连 T-D-T-D…逐音换线，Tap 落拍 Drag 填充）。单线视角只见零星几个。
- **挂线声部**：整段副旋律音符放子线（father=主线），与主线音符**同时段交错**构成双押/交互
  ——与"拆线分段"的区别是子线不独占时段。
- **单音演出线**：可判音符放独立线（挂 father 或 -1）单独运动呈现——游玩时是普通单点，
  视觉由该线专属轨迹强化。
- **跨线同位叠判**：同刻同 x 的叠判定拆在不同线上（x=0/±405/±472 等），
  押数统计必须合并全线时间轴才能算对。
- **空母线挂载**：无音符的母线只承载速度/运动事件，子线挂 father 跟随——既有表演线/单音线挂载，
  也有全部主音符线挂同一条空母线统一变速。
- **密度波浪**：分段 nps 1.4~47 波浪推进（intro 1~2 → verse 10~21 → 峰值 Drag 海 → Hold 铺底回落），
  用密度差制造起伏，不做恒定密度。
- **挂线 father / 文字演出**：见下方「复杂表演手法库」。**假音符已全面禁用**（isFake 恒为 0），不得作为演出手段。

## 复杂表演手法库（AI 表演的推荐手法库）

> 复杂演出**推荐优先从本库选取手法**（P~S 编号），参数按曲风在给定范围内缩放；
> 也可按曲风调整参数或新增手法（编号顺延）。事件字段细节见 [rpe-format.md](rpe-format.md)。

**P. 线组织**

| 编号 | 手法 | 参数模式 |
| --- | --- | --- |
| P1 | 拆线分段 | 音符/演出按段落分线（6~23 条音符线），各线 speedEvents 只覆盖自己负责的段落 |
| P2 | 孪生副线 | 2~8 条线放完全相同的音符（同刻同型同 x）做多份下落画面，主线照常流动 |
| P3 | 挂线组运动 | 表演线 `father` 指向主线/母线，改一处事件即可带动整组道具统一运动 |
| P4 | ~~绑线道具~~ | **禁用**：0 速线不放任何音符；假音符亦禁用，道具/图案演出改用线运动与 alpha（Q/S 类） |
| P5 | 分层管理 | `Name` 按功能命名（main、drag1~8、flick1~6、Perf），`Group`/`zOrder` 管层次 |

**Q. 线运动**

| 编号 | 手法 | 参数模式 |
| --- | --- | --- |
| Q1 | 开场汇聚/结尾收束 | 多表演线 moveY 从 ±1000+ 线性进出屏幕，配 speed 10~12，intro/outro 用 |
| Q2 | 强拍脉冲 | 强拍 rotate ±5~15° 或 alpha 0↔255 短促起伏，1/4~1/2 拍回落，easing 1 |
| Q3 | 左右摆动 | moveX 随乐句 ±150~450 往复分段；主线移动设计见 charting.md"主线情感演出"，大幅摆动放表演线 |
| Q4 | 上下浮动 | moveY ±100~300 配缓动 2/5，叠加 alpha 显隐做呼吸感 |
| Q5 | 段落旋转 | rotate 0→±180 段落级切换（180 = 倒打），过渡 2~4 拍 |
| Q6 | 旋律跟随 | moveX 随音高走向偏移（高音偏一侧，全曲统一方向） |
| Q7 | 变速演出 | drop 前 speed 15~20 + easing 16/17 冲刺，落点回 10~12；低速段（<10）不排密集键 |
| Q8 | 背景大幅演出 | 表演/背景线不限幅，大幅运动都放表演线 |
